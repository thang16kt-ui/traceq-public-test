# Gói minh họa rỗng

Đây là dữ liệu minh họa hợp đồng, không phải dữ liệu vận hành. Tất cả bảng có 0 dòng; SHA-256 trong manifest được sinh từ CSV thực tế trong ZIP. Không đưa gói này vào thư mục incoming sản xuất.

Gói minh họa dùng ID cố định để dễ đọc; export thật dùng UUID do hệ thống cấp và snapshot database.
