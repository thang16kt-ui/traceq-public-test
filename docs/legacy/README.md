và số đo cũ; **không còn đúng với hệ thống hiện tại**. Tài liệu hiện hành: `README.md`, `docs/van-hanh.md`,
`docs/khao-sat-hien-trang.md`, `docs/file-contract.md` (hợp đồng gói xuất – giá trị trạng thái/mức đã đổi, xem README).
